# Modèles vidéo MUNGWELE IA STUDIO

Production defaults are selected only from currently supported provider models.

- Gemini Omni Flash GA: `gemini-omni-1.1-flash`
- Veo 3.1 Standard: `veo-3.1-generate-preview`
- Veo 3.1 Fast: `veo-3.1-fast-generate-preview`
- Veo 3.1 Lite: `veo-3.1-lite-generate-preview`

Omni is preferred for conversational video generation/editing, multiple references, interpolation and reference-to-video workflows. Veo remains available for direct cinematic generation where its pricing/quality profile is preferable.
